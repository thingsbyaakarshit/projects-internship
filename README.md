# Projects Internship Folder

This repository contains multiple small web projects and experiments created during an internship or learning journey. Each project is a separate app with its own files and dependencies.

## Projects included

- blog
- bridge
- chat
- expense-tracker
- infographics
- map
- portfolio

## Structure

Each folder is an independent project and may include:

- HTML pages
- CSS and JavaScript files
- assets and data files
- package.json files for dependencies
- README files specific to the project

## Notes

- Some projects may be static HTML/CSS/JS apps.
- Others may use Node.js or npm-based tooling.
- Check each project’s individual README for specific setup and usage steps.

## Git

This workspace includes a root .gitignore to ignore generated and local files such as:

- node_modules
- .env files
- build output
- OS/editor metadata
